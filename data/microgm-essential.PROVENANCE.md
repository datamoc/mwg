# microgm-essential SoundFont provenance

A preset-only subset of [microgm-opt.sf2](microgm-opt.PROVENANCE.md), with the same
WTFPL licence and unmodified sample data. No additional media or external download.

The six presets use zero-based MIDI numbering: bank 0 programs 0 (piano), 24 (nylon
guitar), 40 (violin), 56 (trumpet), 73 (flute), and bank 128 program 0 (standard drums).
The file is 314,384 bytes. It is optional; the full GM bank remains available.

Regenerate with `npm run build:pkg`, then `node tools/make-essential-soundfont.mjs`.
`tests/soundfont-essentials.test.ts` compares every generated byte to the supplied bank.
Use `missingProgram: 'synth'` with the MIDI renderer for instruments outside this set.
Copy `microgm-essential.sf2` into the game's assets folder; the normal build can subset it further.
