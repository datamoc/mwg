Examples

Eight builds, each exercising a different corner of the framework. Every one runs straight from the framework source and opens the same way a shipped game would — no server behind this page, just file:// pages sitting in an iframe.

Chess

Open full screen

Chess against a small deterministic alpha-beta computer player, with legal moves, check, checkmate, stalemate, castling, en passant, and promotion.

click a square, or hold an arrow key to move the cursor and Enter to select/move  ·  Esc reset

Lockpick minigame

Open full screen

A timing challenge layered over a room scene. It demonstrates scene stacking, suspension, and returning a result to the scene underneath.

Enter stop the needle  ·  Esc leave the minigame

Village

Open full screen

A small RPG map with an NPC, branching conversation, game state, and an autorun cutscene.

Battle

Open full screen

A creature battle with type effectiveness, speed-ordered turns, damage, leveling, and evolution.

Colour transform

Open full screen

4000 individually tinted sprites, each carrying the per-sprite texel × M + A transform that the landing page demo shows in miniature — Pixi's own tint could not draw this scene.

Blank? Build the examples first: npm run webpage:examples (see the repository's webpage/TODO.md).

Interface

Open full screen

Windows that stack, with keyboard focus going to the top one only; a list with icons and disabled rows; a message box that reveals text a character at a time and ends on a choice.

Tab open the bag  ·  Enter talk to someone  ·  arrow keys navigate  ·  Esc close a window

Dialogue

Open full screen

A conversation scene: a backdrop, Alice and Bob standing in front of it with expressions, whoever is speaking lit while the other is dimmed, and a branching choice. The whole scene is a list of data commands.

Enter / Space advance the conversation

Dungeon crawl

Open full screen

A playable roguelike floor: generated rooms and corridors, three-state fog of war, bump-to-attack, monsters that give chase, stairs down. The full roguelike module working together with render and ui.

arrow keys or numpad move and bump to attack  ·  5 / . wait  ·  > descend on the stairs

running them yourself

From source

Each example also runs against the framework's live source, so editing src/ reloads the page:

npm run assets              # generates examples/assets, once

npm run example             # colour-transform, dev server
npm run example:ui          # interface, dev server
npm run example:dialogue    # dialogue scene, dev server
npm run example:dungeon     # dungeon crawl, dev server
npm run example:village     # village RPG, dev server
npm run example:battle      # creature battle, dev server
npm run example:minigame    # lockpick minigame, dev server
npm run example:chess       # chess against the built-in engine, dev server

Append :build to any of those to produce a folder you open from disk with no server at all — see examples/README.md for the full list.
