# @datamoc/mw_games

The former name of [`@datamoc/mwg`](https://www.npmjs.com/package/@datamoc/mwg).

```
npm install @datamoc/mwg
```

New projects install the main name above; this package only forwards to it.

`import { Game } from '@datamoc/mw_games/two-d'` is the same module as `import { Game } from '@datamoc/mwg/two-d'`. The `mwg-*` command line tools are installed by `@datamoc/mwg`; run them with `npx -p @datamoc/mwg mwg-emit`. Documentation: https://datamoc.github.io/mwg/
