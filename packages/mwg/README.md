# @datamoc/mwg

The short name for [`@datamoc/mw_games`](https://www.npmjs.com/package/@datamoc/mw_games).

```
npm install @datamoc/mwg
```

`import { Game } from '@datamoc/mwg/two-d'` is the same module as `import { Game } from '@datamoc/mw_games/two-d'`. The `mwg-*` command line tools are installed by `@datamoc/mw_games`; run them with `npx -p @datamoc/mw_games mwg-emit`. Documentation: https://datamoc.github.io/mwg/
